# Next.js SaaS Starter Kit

A complete SaaS boilerplate with everything wired up — auth, payments, and a polished UI. Skip the setup, start building your product.

## What's included

- **Auth** — Better Auth with email/password and OAuth
- **Payments** — Stripe subscriptions and webhooks
- **UI** — shadcn/ui + Tailwind CSS + dark mode
- **Database** — Prisma ORM ready to connect
- **Next.js 15** — App Router, server actions, middleware

## Getting Started

```bash
git clone https://github.com/sh00von/nextjs-stripe-betterauth-shadcn-starter-kit
cd nextjs-stripe-betterauth-shadcn-starter-kit
npm install
cp .env.example .env.local
npm run dev
```
